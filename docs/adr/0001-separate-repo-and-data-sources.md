# 0001. Отдельная репа, источники данных

## Контекст

Идея — инвестировать строго по рекомендациям телеграм-канала, без внутридневной механики.
Из `bcs-trading-bot` полезен разве что клиент БКС, и тот понадобится только для реального
исполнения. Модель исполнения бота (бары M15, стопы, EOD) здесь не применима.

## Решение

- Отдельная репа на Go (язык основного проекта).
- Посты — через порт `ChannelSource`: веб-превью `t.me/s/<канал>` для публичных каналов,
  экспорт Telegram Desktop для остальных; MTProto — когда понадобится закрытый канал
  или канал с запретом копирования (экспорт Desktop там недоступен).
- Цены — MOEX ISS без авторизации: дневные бары с 2020 года, включая делистнутые бумаги,
  список бумаг тоже с делистнутыми.

## Последствия

- ISS **не отдаёт дивиденды** бесплатно (`/iss/cci/corp-actions/dividends` — «только подписчикам»)
  и **не корректирует цены**. Сплиты и смены тикеров — ручная таблица
  `data/corporate_actions.json`; без записи прогон останавливается, а не считает молча.
- Сравнение пока ценовое с обеих сторон: бумаги без дивидендов против IMOEX (ценовой индекс).
- У ушедших с биржи бумаг (POLY, QIWI, SFTL) ISS с фильтром `marketprice_board=1` отдаёт пусто —
  клиент повторяет запрос без фильтра.
- Веб-превью видит только факт правки поста, не время; удалённые посты — только как дыры в ID.
