# 0004. Портфель-дневник: повторяем сделки автора (Trendoman, «Идея на миллион»)

## Контекст

Канал закрытый, история — HTML-экспорт Telegram Desktop (`data/exports/<канал>/`, не в git).
Это не сигналы с целью, а дневник счёта: еженедельный взнос 10 000 ₽ (#ВзносN), каждая сделка
с количеством и суммой (#Покупка/#Продажа), реинвест купонов (#Купоны), размещения (заявка →
отчёт «насыпал на X р»). С 13.02.2023 — новый счёт («канал перезапускается»), старый брошен
после блокировки брокером; считаем с 2023-02-13. С 2024 портфель почти целиком в облигациях
(ВДО, ОФЗ, юаневые/долларовые выпуски), местами на заёмные.

Текст свободный и грязный: копипаст сумм из соседних постов, «86 лотов (125шт)», точка как
разделитель тысяч («13.267»), цена за штуку вместо суммы («1 лот (100шт) 32.67р»), сделки
в постах без тега сделки.

## Решение

- **Разбор кодом + ручные правки** (`data/diary/<канал>/{aliases,fixes}.json`), не разбор глазами:
  один код для истории и новых постов. У каждой правки — `note` с доказательством.
- **Каждая сделка сверяется с рынком дня поста** (`resolve`): цена из суммы автора обязана попасть
  в диапазон дня ±3% (облигации ±2%). Варианты по порядку: заявленные штуки; «сумма» как цена за
  штуку; лоты; ×1000 для «13.267»; количество из суммы — последнее, с допущением в отчёте.
- **Количество согласуется один раз** до обеих моделей; модели отличаются только ценой:
  - *автор* — день поста, его сумма;
  - *последователь* — open первой сессии после поста, комиссия 5 б.п.
  - размещения — по номиналу в первый день торгов у обоих (заявку подают до торгов);
  - оферта (Сегежа 2024-11) — цена из правки, не рыночная.
- **Счёт**: взносы из постов (номер в пределах 3 дней — один взнос), купоны — держали на конец
  дня перед реестром, амортизации и погашение из ISS bondization, дивиденды акций (ADR 0003),
  валютные облигации — по курсу ЦБ (USD на бирже с 2024-06 не торгуется), долг — LQDT + 4% годовых.
- **Сверки**: «Общая позиция N шт» автора против нашей позиции; состав из #БалансПортфеля
  (списки автора неполные — отчёт, не гейт).
- **Бенчмарки**: те же взносы в те же дни в MCFTR (выбор владельца) и справочно в LQDT —
  безрисковая альтернатива облигационному портфелю.
- **Журнал** — у последователя (`data/ledger/<канал>-follower.jsonl`), сверка прошлого как в 0002.

## Последствия

- Обход map в движке — только по отсортированным ключам: иначе порядок операций внутри дня
  случаен и журнал не сверяется со вторым прогоном.
- Продажи без поста не восстанавливаются: устойчиво «лишние» у нас MTLR, MTLRP, YNDX→YDEX, MAGN
  (~2% капитала на конец) — оговорка в разборе.
- Новый пост — новый прогон; что не разобралось или не сошлось с рынком, останавливает журнал.
