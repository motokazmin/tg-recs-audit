# 0002. Правила виртуального портфеля

> Бенчмарк и дивиденды изменены в [0003](0003-dividends.md): MCFTR вместо IMOEX, выплаты начисляются.

Зафиксированы 2026-10-16 **до первого прогона**. Менять — новым ADR и новым журналом,
не правкой старого: журнал сверяется с пересчётом, и изменённое прошлое остановит `run`.

## Контекст

`@ruforecasts` (investmint) пересказывает идеи брокеров по шаблону: тикер, целевая цена,
дата идеи, аналитик. Продаж канал не публикует, закрытий идей тоже. Пост выходит в медиане
через 9 дней после даты идеи (p90 — 35 дней). 2–3 идеи в торговый день.

## Решение

| Правило | Значение |
|---------|----------|
| Вход | open первого торгового дня **после дня поста** (МСК). Дневной бар ISS с 2025 открывается утренней сессией 07:00 — раньше поста в 09:03 |
| Размер | 10 000 ₽ на идею, целое число акций, минимум одна; капитал не ограничен |
| Выход по цели | лимит по цели; если open уже выше — по open («цель (гэп)») |
| Выход по горизонту | **основной: `year-end`** — close последнего торгового дня года входа (выбор владельца: «аналитики имеют в виду до конца года»); для сравнения `<N>m` — последний торговый день не позже входа + N месяцев (проверены 12m и 1m) |
| Цель достигнута до входа | пропуск |
| Повторная идея, пока бумага в портфеле | пропуск с записью; `-stack` — проверка устойчивости, не альтернатива |
| «Держать» / «Продавать» | пропуск |
| Комиссия | 5 б.п. на ногу |
| Бенчмарк | IMOEX теми же деньгами в те же дни |
| День сплита | только close: бар бывает смешанным (BELU 2024-08-22: open 4223 в старом масштабе, close 714 в новом) |
| Торги прекращены без преемника | закрытие по последнему close, только по записи `frozen` |

Капитал не ограничен, потому что при фиксированном кэш кончается за ~100 идей, и результат
зависит от того, какие идеи пришли первыми. Сколько денег понадобилось бы на самом деле —
«на пике вложено» в отчёте.

## Последствия

- Декабрьские идеи при `year-end` живут дни — в отчёте отдельной строкой.
- 72% идей — повторы по бумаге в портфеле; поэтому `-stack` обязателен как проверка.
- Журнал дописывается только днями строго раньше последнего бара IMOEX: незакрытый день не фиксируется.
