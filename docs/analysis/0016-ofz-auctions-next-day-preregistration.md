# 0016. Аукционы ОФЗ, выход на следующий день: регистрация

Написано **до прогона** 2026-10-17. Результат — 0017, этот файл не переписывать.

## Что уже видели (честно)

В 0015 на тех же 254 аукционах выход **через 1 день по CLOSE TQOB** дал +0.27% к LQDT, t 3.8 —
горизонт выбран после просмотра. Эта проверка на тех же данных **не независима**; она меняет
цены на исполнимые (ниже) и добавляет контроль. Независимая проверка — только вперёд (paper).

## Что выяснили до прогона (смысл цен ISS)

- PACT `CLOSE` = `VALUE / VOLUME` — **средневзвешенная цена аукциона** (26248 на 2025-02-12:
  767.25 ₽ = 76.7252%); `LOW` — цена отсечения. Неконкурентная заявка физлица исполняется по
  средневзвешенной — вход 0015 был исполнимым.
- TQOB `CLOSE` — последняя сделка, **включая вечернюю сессию** (2025-02-12: 79.85 при официальном
  закрытии 76.80). Для выхода — `LEGALCLOSEPRICE` (официальное закрытие, исполнимо в аукционе
  закрытия) и `WAPRICE` (средневзвешенная дня).

## Правило

- Событие — аукцион размещения ОФЗ (доска PACT, сделки > 0), 2020…2026-09.
- Вход — средневзвешенная цена аукциона (PACT `VALUE/VOLUME`, % номинала) + НКД.
- **Основной выход** — `LEGALCLOSEPRICE` TQOB следующего торгового дня + НКД. Купон между — в доход.
- Издержки 5 б.п. на ногу. Бенчмарк LQDT (close дня аукциона → close дня выхода).
- Дополнительно: выход по `WAPRICE` следующего дня; по `OPEN` следующего дня.
- **Контроль** (что дал бы рынок без аукциона): покупка той же ОФЗ на TQOB по `LEGALCLOSEPRICE`
  дня аукциона, выход так же. «Премия аукциона» = основной − контроль.

## Критерии

Механизм годится, если **все** для основного выхода:
1. Среднее превышение над LQDT > 0 и медиана > 0.
2. t > 2 по неделям.
3. Тот же знак в половинах (до 2024 и с 2024).
4. Премия аукциона (основной − контроль) > 0 с t > 2 — прибыль от цены размещения, а не от
   того, что ОФЗ в эти дни росли.

Разрезы (описательно): ПД / ПК / ИН, объём аукциона (терцили), уступка к официальному закрытию
дня аукциона.
