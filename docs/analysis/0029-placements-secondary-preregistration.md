# 0029. Новые выпуски на вторичке: покупка по закрытию первого дня — регистрация

Написано **до прогона** 2026-10-17. Результат — 0030, этот файл не переписывать.

## Зачем

0020: доход размещений за день — в горячих книгах, где аллокация маленькая. Вторичка аллокации
не знает: купить можно сколько угодно по рынку. Вопрос — продолжается ли движение после первого
дня (горячие дорожают дальше, холодные отыгрывают) настолько, чтобы покупать на бирже.

## Что уже видели (честно)

В 0020 видели доходность «номинал → закрытие следующего дня» по корзинам close первого дня
(> 100.5 — +1.1…3.6%, ≤ 100.5 — −0.04%). Движение **после** первого дня не смотрели.

## Правило

- Выборка 0007/0019: `data/analysis/placements.csv` (n = 20, по номиналу), первые торговые дни —
  `data/cache/iss/plhead/` (официальное закрытие `LEGALCLOSEPRICE`, иначе `CLOSE`).
- День 1 — первый торговый день со сделками. Вход — официальное закрытие дня 1 + НКД (исполнимо в
  аукционе закрытия), выход — официальное закрытие **5-го торгового дня после** + НКД; купоны в окне
  (их почти нет) не учитываются — оговорка в пользу нуля. Издержки 5 б.п. на ногу, против LQDT.
- Корзины по close дня 1 (известно на входе): **горячие > 100.5**, **холодные < 99.8**, остальные —
  описательно.

## Критерии

Для каждой из двух корзин отдельно (две гипотезы — планка t > 2.5):
1. Среднее превышение над LQDT > 0, медиана > 0, t > 2.5 по неделям.
2. Тот же знак в 2023–2024 и 2025–2026.

Ожидание заранее: близко к нулю — рынок облигаций обычно доводит цену до справедливой в первый день.
