# 0033. Горячие размещения на вторичке: отложенная выборка 2021–2022 — регистрация

Написано **до прогона** 2026-10-17. Результат — 0034, этот файл не переписывать.

## Зачем

0030: горячие выпуски (официальное закрытие дня 1 > 100.5%), купленные по закрытию дня 1 и
проданные через 5 торговых дней, дали +0.44% к LQDT (t 3.1) на 2023–2026. Отложенной выборки не было:
выборка 0007 начинается с 2023. Размещения 2021–2022 никто не смотрел — это и есть проверка.

## Выборка

Отбор 0006 (`placements.Universe`) тем же кодом в Python: корпоративные и биржевые, `RU000A…`,
номинал в рублях, без «ИОС», купон в карточке ≥ 1% или задан суммой; ISSUEDATE 2021-01-01…2022-12-31;
первый день торгов по 97–103% (иначе «не по номиналу», как `NotPar`). Карточки и первые дни — ISS
(кэши `cards/`, `plhead/`, как в 0019).

## Правило — без изменений против 0029

- Вход — официальное закрытие (`LEGALCLOSEPRICE`, иначе `CLOSE`) первого торгового дня + НКД,
  выход — официальное закрытие 5-го торгового дня после + НКД; 5 б.п. на ногу.
- Горячие — закрытие дня 1 > 100.5.
- **Бенчмарк**: LQDT, где он есть (с 2022-07-22); раньше — ключевая ставка ЦБ (cbr.ru) за календарные
  дни окна. Ставка выше доходности LQDT на ~0.3–0.5 п.п. годовых — это против стратегии (~0.01% за окно).
- Торговый календарь до LQDT — дни торгов MCFTR.

## Критерии

На горячих 2021–2022: среднее превышение > 0, медиана > 0, t > 2 по неделям. Половины — описательно
(2022 — кризис, февраль–март без торгов).
