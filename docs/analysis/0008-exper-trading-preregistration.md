## Канал

t.me/Exper_Trading (ExpertTrading, 16K), публичный, 6615 постов с 2019-12. Сигналы по фьючерсам
FORTS карточкой: инструмент и контракт (`#NG-02.26`), тип (buy/sell limit, buy/sell stop,
по рынку), цена, стоп, тейк (в 65% «Открытый»), срок («Сегодня до 23:50», дата, «До отмены»).
Дальше ручное ведение постами («безубыток», «фиксируем», «переносим стоп») — **не повторяем**:
проверяем ядро — карточку, исполняемую правилом. 2518 карточек.

## Правило исполнения (как в боте: решение по бару не зависит от его закрытия)

- Свечи — 10-минутные ISS по контракту из карточки; код: префикс + месяц + цифра года
  (BR-11.26 → BRX6; MIX→MX, SILV→SV, GOLD→GD, Si→Si, SBRF→SR, GAZR→GZ, RTS→RI, CNY→CR, …).
- Ордер живёт с первой свечи, **начавшейся после поста**, до: «Сегодня до 23:50» — 23:50 дня поста;
  дата — 23:50 этой даты; «До отмены» или нет срока — **5 торговых дней**. Новая карточка по тому
  же инструменту снимает неисполненный ордер.
- Вход: limit — касание цены, фил по цене (открытие свечи за ценой — по open); stop — пробой,
  фил по цене или по худшему open; по рынку — open первой свечи после поста.
- Свеча фила: проверяется только стоп (худший случай), тейк — со следующей.
- Выход: стоп (на гэпе — по open); тейк из карточки, а если «Открытый» — **2R**; иначе закрытие
  через **5 торговых дней** после фила по close; истечение контракта — по последнему close.
- Издержки: 0.05% цены на ногу (комиссия + проскальзывание), в R.

## Метрики и критерии

Основная — средний R на исполненную сделку после издержек. Механизм годится, если **все**:
1. Средний R > +0.05 и медиана > 0.
2. t > 2 по неделям сигнала (R усредняется внутри недели).
3. Тот же знак в половинах: карточки 2019–2022 и 2023–2026.
4. Плюс хотя бы в 2 из 3 групп: сырьё (BR, NG, GOLD, SILV, PLT), индексы и валюта (RTS, MIX,
   Si, CNY, ED, EU, SPYF), фьючерсы на акции (SBRF, GAZR, VTBR, LKOH, MGNT, ROSN, SBER).

Диагностика «есть ли смысл в уровне»: те же стоп и 2R, но вход **по рынку в момент поста**
вместо лимита на уровне. Если уровень ничего не добавляет — лимит не лучше рынка.

Разрезы — описательно: тип ордера, срок, тейк автора против 2R, год.
