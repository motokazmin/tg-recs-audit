## Почему разметка по торгам не годится

Проверка на корзине < 90% прошла (Фабрика Фаворит — «дефолт»). Но в основной корзине «дефолтом»
по торгам помечены **ГТЛК, Совкомбанк, ТрансФин-М, УОМЗ, ЕАБР** — эмитенты, которые оферты
исполнили. Механизм: перед офертой эмитент ставит низкий новый купон, держатели сдают бумаги по
100%, а остаток выпуска торгуется по 60–90%. Close < 90 после оферты — это **сброс купона**,
а не дефолт. Разметка ошибается в пессимистичную сторону, как ISS — в оптимистичную.

Вывод: правда между −0.5% и +2…6% к LQDT на 38 событиях, и узнать её можно только по списку
дефолтов. Медиана положительна в обеих разметках (+2.3…2.5%), но среднее держат несколько
событий с ошибочной разметкой — этим цифрам верить нельзя.

## Что нужно, чтобы закрыть вопрос

Список кредитных событий по эмитентам (Cbonds, рейтинговые агентства, раскрытие e-disclosure).
Публичной машиночитаемой таблицы не нашлось; Cbonds считает 325 кредитных событий в 2025.
Альтернатива — разметить вручную 11 событий основной корзины, помеченных по торгам как дефолт
(список печатает скрипт), по раскрытию эмитентов. Это владелец может сделать за полчаса;
по памяти не размечаю — так уже ошибался.

Идея 6 остаётся **не подтверждена**; корзина маленькая (≈ 7 событий в год), даже при успехе это
дополнение, а не стратегия.
