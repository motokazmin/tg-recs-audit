# 0031. t.me/finamalert: торговые идеи Финама — регистрация

Написано **до прогона** 2026-10-17 (смотрели только формат постов и их число). Результат — 0032,
этот файл не переписывать.

## Канал

«Финам Торговые сигналы», публичный, 21 353 поста 2018-01…2026-10, правок 8%. Внутри — дайджест
чужих мнений и **карточки идей аналитиков Финама** двух форматов:

- 2018–2021: «Россети, ао (RSTI) ПОКУПАТЬ… Инвестиционный горизонт 1-3 мес. Цена входа… Цель…
  Стоп приказ…» (~2300 постов со стопом и целью, вместе с иностранными бумагами, валютой, фьючерсами
  и повторами-закрепами);
- 2022–2026: «Тикер AFLT / Идея: Long / Срок идеи: 3-4 недели / Цель / Стоп-приказ» (1400 карточек,
  Long 1261, Short 139).

## Выборка

Карточки по акциям TQBR (тикер есть в ISS на TQBR); без закрепов («pinned») и повторов (тот же тикер,
направление и цель за 7 дней). Две выборки: **A — 2018–2021** (старый формат), **B — 2022–2026**.

## Правило (подписчик)

- Вход — open следующего торгового дня после поста, по рынку (условный вход «при достижении X»
  не повторяется — описательно отдельно).
- Стоп и цель — из карточки; цель или стоп уже за ценой входа — пропуск.
- Горизонт — верхняя граница из карточки («3-4 недели» → 4 недели, «1-3 мес.» → 3 месяца),
  в календарных днях; по истечении — выход по close. Без горизонта — 1 месяц.
- Дневные бары: стоп и цель по low/high; в один день — считается стоп; гэп через уровень — по open.
  Издержки 5 б.п. на ногу. Шорт — без платы за займ (оговорка).
- Превышение: доходность сделки − MCFTR (close дня до входа → close дня выхода); у шорта — минус
  доходность бумаги минус MCFTR не вычитается, а прибавляется (хедж индексом).

## Критерии

Канал даёт преимущество, если **на обеих выборках A и B** по Long-идеям:
1. Среднее превышение над MCFTR > 0, t > 2 по неделям.
2. Тот же знак и у медианы.

Short — описательно (мало). Ожидание: как ruforecasts (0001–0004) — около нуля или хуже индекса.
