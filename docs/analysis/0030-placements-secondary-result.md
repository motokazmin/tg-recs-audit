## Проверки на прочность (описательно, после просмотра)

| горячие | N | среднее | t |

| ставка растёт / стоит / падает | 46 / 136 / 67 | +0.55% / +0.30% / +0.65% | 1.3 / 2.3 / 3.1 |
| минус средняя корзина той же недели | 244 | +0.26% | 1.94 |
| **вход по open дня 2 вместо закрытия дня 1** | 249 | **+0.27%**, медиана +0.02% | 1.91 |
| close дня 1: 100.5–101 / 101–102 / > 102 | 133 / 80 / 36 | +0.37% / +0.26% / +1.13% | 2.3 / 1.5 / 1.95 |

- Плюс во всех фазах ставки — не только снижение ставки.
- Около 40% дохода — между закрытием дня 1 и открытием дня 2. Стратегия держится на покупке
  в аукционе закрытия первого дня; вход утром следующего дня даёт уже на грани шума.
- Против средних выпусков той же недели — +0.26% (t 1.9): часть дохода — общий рост рынка новых
  выпусков, не только «горячесть».

## Что это значит

Первая идея по размещениям **без проблемы аллокации**: на вторичке покупается сколько угодно
(в пределах ликвидности первых дней). +0.44% за 5 дней на задействованный капитал, ~250 событий
за 3.7 года (~1.3 в неделю). Отложенной выборки нет (размещения в кэше — с 2023), поэтому
проверка — только вперёд.
