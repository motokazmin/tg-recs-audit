# 0023. Пут-оферты: дефолт по торгам после оферты — регистрация

Написано **до прогона** 2026-10-17. Результат — 0024, этот файл не переписывать.

## Что уже видели (честно)

0015 на тех же 755 офертах: при «исполнена, если ISS не пометил дефолт» цена входа 90–95% →
+6.3% к LQDT, 95–97% → +2.1%, 97–99% → +0.3%; ниже 90% — +210%, явный сбой: ISS помечает не
все дефолты. Выборка и вход те же, меняется только **определение исполнения** — оно больше
не берётся из типа оферты ISS. Проверка на тех же данных не независима; она отвечает на вопрос,
держится ли результат 0015, если не верить разметке ISS.

## Независимая разметка: торги после оферты

Источник — история торгов выпуска на **всех досках** (`data/cache/iss/offers/<secid>.json`),
окно — 60 торговых дней (по календарю LQDT) после даты оферты.

- **Исполнена**: в окне были сделки, и все close ≥ 90% номинала. Эмитент, выкупивший бумагу
  по номиналу, не оставляет её на рынке по 70%.
- **Дефолт**: в окне был close < 90%. Выход — первый close после даты оферты (рынок, по которому
  можно продать), купоны по этот день; издержки 5 б.п.
- **Неизвестно**: после оферты сделок нет (выкупили всё или бумагу убрали с торгов).
  - нижняя граница (основная): считать как дефолт с выходом по последнему close **до** оферты;
  - верхняя граница: считать исполненной.

Тип ISS в разметке не участвует; описательно — таблица совпадения с ISS.

## Критерии

На группе цена входа **90–97%** (где 0015 нашёл эффект), нижняя граница:
1. Среднее превышение над LQDT > 0 и медиана > 0.
2. t > 2 по неделям.
3. Тот же знак в половинах (до 2024 и с 2024), если в каждой ≥ 5 событий; иначе — описательно.

Остальные корзины (< 90, 97–99, ≥ 99) — описательно. Проверка разметки на корзине < 90:
если «исполнена» по торгам там всё ещё у бумаг вроде Фабрики Фаворит — разметка сломана,
результат не принимать.
