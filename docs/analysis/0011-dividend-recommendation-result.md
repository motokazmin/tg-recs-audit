# 0011. Покупка после рекомендации дивидендов: результат

Регистрация — [0010](0010-dividend-recommendation-preregistration.md). Команда:
`recaudit divevents t.me/divonline`. События 2021–2026 из постов «Рекомендованы дивиденды».

## Отклонение от регистрации

Регистрация брала дивиденд из поста. Рекомендацию совета может отменить собрание (часто
в 2022) — тогда цена уже ждала выплату, а её нет. Добавлено: дивиденд начисляется, только если
smart-lab подтверждает выплату с T-1 в пределах недели; не подтверждено 24 события — дивиденд 0.
Это ухудшает результат (+4.36% → +3.06%); все цифры ниже — после этой проверки.

## Что это значит

- Разгон к отсечке есть и без дивиденда (A): +2.65% к индексу за ~6 недель — рынок
  недооценивает объявленную выплату в день объявления, подписчик успевает зайти на следующий день.
- Держится на крупных выплатах: верхняя треть по доходности +8%, 78% в плюсе; нижняя — минус.
  Это описательно (не для отбора), но совпадает с механизмом — под большую выплату покупают.
- Годовые выплаты +3.65% (391), промежуточные +1.63% (160, t 1.4) — описательно.
- **Сжимается**: с 2024 превышение втрое меньше, чем до (+1.35% против +4.99%) — эффект
  известный, в него приходят деньги.

## Оговорки

- События — только те, что опубликовал канал; отбор не по исходу, но не весь рынок.
- Вход по open следующего дня после поста: если канал публикует с опозданием на часы, часть
  реакции уже в цене — оценка в этом смысле консервативна.
- Налог учтён только в отдельной строке; бенчмарк MCFTR — брутто.
- Сплиты в окне — событие пропускается (1 случай).
