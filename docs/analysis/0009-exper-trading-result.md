## Что из этого полезно

- **До издержек ноль, после — минус**: при медианном стопе 1.8% цены издержки 0.05% на ногу
  стоят ~0.12R; на узких стопах (треть сделок, ~0.8% цены) — 0.26R на сделку
  (−0.10R → −0.37R). Узкий стоп сам по себе превращает нулевую стратегию в убыточную —
  то же, что держит гейт `min_stop_bps` в боте (`~/pet-projects/bcs-trading-bot`).
- Ручное ведение автора (безубыток, фиксация, перенос стопа) не повторялось — оно не
  исполнимо правилом и в карточке не обещано; если в нём и есть умение, по постам его не отличить
  от подгонки задним числом.
- Инструмент `signals` (карточки, FORTS 10 минут, исполнение как в боте) годится для других
  каналов с сигналами по фьючерсам.

Описательно, не для отбора: средняя треть по ширине стопа +0.14R до издержек; выход по времени
+0.39R — метка по исходу, выводов не делать.
