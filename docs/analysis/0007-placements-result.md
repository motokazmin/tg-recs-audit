# 0007. Размещения облигаций по номиналу: результат

Регистрация — [0006](0006-placements-preregistration.md). Команда: `recaudit placements`.
Данные — ISS, LQDT как денежный рынок, 2023-01 … 2026-07 (выход до 2026-10).

## Отклонения от регистрации — все по устройству данных, не по результату

1. **Прогон 1** (по букве регистрации): 1779 размещений, среднее превышение +11.5% за 20 дней
   при медиане +0.48%. Среднее тянули структурные ноты: у Сбер CIB-SN, ВЭБ.РФ ПБО-К, банковских
   нот купона в карточке нет вовсе, а правило «купон < 1%» на пустом значении не срабатывает
   (NaN < 1 — ложь). Дополнено: «купона в карточке нет (ни процента, ни суммы) — нота».
   Флоатеры остаются — у них купон задан.
2. **Прогон 2**: 1057, среднее +1.42%. Остаток хвостов — выпуски, размещённые не по номиналу
   (ВЭБ ПБО-К по 110–300%, дисконтные с купоном 1–2%): допущение «вход 100%» для них неверно.
   Дополнено: цена первого дня торгов вне 97–103% — исключить (известна в момент входа).
   Заодно возврат номинала считается по его уменьшению в барах, а не по графику ISS:
   ипотечные облигации ДОМ.РФ гасятся внепланово.
3. **Прогон 3** — итог ниже. Единичные артефакты остались (один ВЭБ ПБО-К +97%, ипотечные
   ДОМ.РФ до −26%): среднее без 1% хвостов +0.98% против +1.06% — вывод не меняют.

**Все четыре критерия 0006 выполнены.** Премия новому выпуску есть на всём рынке, в обеих
половинах и во всех фазах ставки; основная часть набирается за первые 1–4 недели (к 60 дням
превышение почти не растёт). Разрезы (описательно): больше у выпусков с купоном сильно выше
ставки (+1.42% в верхней трети против +0.90% в нижней) и у небольших выпусков.

## Почему это верхняя оценка

- **Аллокация.** Считали, что дают 100% заявки. На спросовых выпусках (которые потом и растут)
  заявку режут — у Trendoman 58% на Биннофарм, 85% на ВИС. Худшие выпуски дают целиком.
  Реальная премия на рубль заявки ниже, насколько — по этим данным не оценить.
- **Доступ.** 138 из 1016 — только для квалифицированных; часть книг закрывается за минуты.
- **Кредитный риск** за 20 дней почти не проявляется; дефолтный выпуск в окне — редкость, но
  держать дольше — значит брать и его.
- 129 выпусков без сделок за 20 дней не вошли в средние — продать их было бы негде.

## Что дальше

Гипотеза для следующей регистрации — правило «подаём заявку на каждое размещение с купоном
выше ставки на X п.п. и номиналом в рублях, продаём через 20 дней» с учётом реальной аллокации.
Аллокацию можно оценить только вживую: paper-участие в размещениях вперёд и запись,
сколько дал брокер.
