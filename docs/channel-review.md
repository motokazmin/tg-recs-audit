# Как разбирать новый канал

Порядок, на котором сложились разборы 0001–0007. Каждый шаг отвечает на вопрос, без ответа
на который следующий не имеет смысла.

## 1. Доступна ли история

- Публичный: `make check-channel CHANNEL=t.me/имя` — глубина, удалённые (дыры в ID), правки.
- Закрытый: экспорт Telegram Desktop → `data/exports/<имя>/` (HTML или JSON, **не коммитить** —
  платный контент). «Экспорт истории чата» недоступен — включён запрет копирования; тогда только
  MTProto через аккаунт (источник ещё не написан).
- Перезапуски и смены счёта («канал перезапускается») — отмечать: результат «с перезапуска»
  — выбор периода в пользу автора.

## 2. Что за канал

| Тип | Признак | Механика |
|-----|---------|----------|
| Идеи с целью | тикер, целевая цена, аналитик | `run` — `feature/ideas` + `portfolio` (нужен парсер шаблона) |
| Дневник портфеля | взносы, сделки с количеством и суммой | `diary` — `feature/diary` (синонимы и правки в `data/diary/<имя>/`) |
| Сигналы трейдинга | вход/стоп/тейк, внутри дня | пока нет — нужна модель исполнения на барах (ближе к боту) |
| Обзоры без сделок | мнения, макро | повторять нечего — только выписать механизмы в `ideas.md` |

## 3. Повторение на истории

- Две планки: **MCFTR** (акции, полная доходность) и **LQDT** (деньги без риска) — теми же
  деньгами в те же дни. Для портфеля без акций главная — LQDT.
- Две модели цены: как у автора и как у подписчика (open следующей сессии).
- Сверки с тем, что автор сам пишет («общая позиция», состав портфеля), — расхождение
  объяснить до вывода.
- Правило выхода, если автор его не даёт, — записать до прогона.

## 4. Механизмы внутри, а не только итог

Итог канала может быть плохим при рабочей механике внутри (Trendoman: портфель хуже LQDT,
размещения — лучше). Разложить доход по типам действий автора; выписать кандидатов в `ideas.md`.

## 5. Проверка кандидата на всём рынке

- Регистрация `analysis/NNNN-…-preregistration.md` **до прогона**: вселенная, правило, горизонты,
  бенчмарк, критерии (t по кластерам, обе половины периода, фазы рынка).
- Вселенная — с погашенными, делистнутыми и дефолтными бумагами.
- Результат — отдельным файлом; отклонения от регистрации — списком, с цифрами каждого прогона.
  Отклонение допустимо только по устройству данных (поле карточки, данные на момент входа),
  не по результату.
- Метки из будущего («дошла до цели», «был ретест») для отбора не использовать.

## 6. Запись

- Разбор — `analysis/NNNN-*.md`, старые не переписывать.
- Статус идеи — `ideas.md`.
- Новые грабли — в `CLAUDE.md` (утверждение + чем подкреплено).
